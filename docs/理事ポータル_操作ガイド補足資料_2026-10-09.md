# 理事ポータル 操作ガイド 補足資料（2026-10-09）

NPO法人 日本繊維商品めんてなんす研究会（TeMA）理事ポータル

この資料は「理事ポータル 機能説明書（2026-10-09）」を補うものです。機能説明書は「画面ごとの説明」、この資料は「やりたいこと別の手順」「困ったときの対処」「最新の変更点」をまとめています。

機能説明書（2026-10-09）とこの資料が最新版です。これより古い版の機能説明書と内容が食い違う場合は、最新版が正しい内容です。

## 3. やりたいこと別の手順

### 3-1. 新しい講座を登録する
1. トップ画面の「講座一覧」で「＋ 新しい講座を追加」を押す。
2. 講座名・開催日・開催場所・講座の開始／終了時刻・講師依頼時間・担当理事・担当科・研修形式・ステータスを入力して保存する。
   - 講師依頼時間は、講師の方に来てもらう時間（集合や打ち合わせを含む）。講座の時間と同じなら空欄でよい。
3. 保存すると、共有Googleカレンダーにも予定が自動で入る。
4. 続けて、講座カードを押して「講座進捗」ページを開き、「PDF機能」から講座案内PDFを登録する（15MBまで）。

### 3-2. 講師に請書兼請求書を送る
1. 請求書管理簿を開き、「＋ 新規作成」を押す（講座進捗ページの「請求書を作成する」からでも可。この場合は講座の情報が自動で入る）。
2. 「講座から選択」で講座を選ぶと、開催日・時間・場所・テーマなどが自動で入る。
3. 謝礼（税抜）、交通費・宿泊費の扱い（含む／別途支給）、支払方法、支払予定日、準備機材、講師へのメッセージを入力して保存する。
4. 保存すると講師用リンクが表示されるので「コピー」を押し、メールやLINEで講師に送る（案内文も一緒にコピーされる）。
5. 後からリンクをコピーし直すときは、一覧の該当行の「その他の操作」→「案内文とリンクをコピー」。

※ 講師用リンクをコピーするボタンは、一覧の「その他の操作」の中にある「案内文とリンクをコピー」です。

### 3-3. 講師が確定した請書兼請求書を修正したい（差し戻し）
講師が「内容を確定する」を押した後は、講師本人はリンクから内容を変更できません。修正が必要なときは次の手順で「差し戻し」ます。

1. 請求書管理簿で該当の請求書の「その他の操作」を押す。
2. 「講師に差し戻す（修正してもらう）」を押し、差し戻す理由を入力する（空欄でも可）。
3. 請求書が「作成済み」に戻る。講師の方に「同じリンクから修正して、もう一度確定してください」と連絡する。
4. 講師がリンクを開くと、前回入力した内容が入った状態で表示されるので、直す部分だけ修正して確定できる。

- 差し戻せるのは「確定済み」の請求書だけです。「支払い済み」「取消」は差し戻せません。
- 謝礼額・開催日時など、理事側が入力した項目を直すときは、差し戻しは不要です。「その他の操作」→「編集」で直せます。
- 誰がいつ、どんな理由で差し戻したかは記録（ActivityLog）に残ります。
- スプレッドシートを直接書き換える方法は、記録が残らず、講師の署名と内容が食い違うため、原則として使いません。

### 3-4. 講師への支払いを済ませる
1. トップの「支払い待ちタスク」で、支払予定日の近い請求書を確認する（「確定済み」になっていないものは、まだ講師の確定待ち）。
2. 振込担当者に渡す場合は「振込担当者用に一括印刷」→「印刷する」（3-5参照）。
3. 振込が済んだら、請求書管理簿で「その他の操作」→「支払い済みにする」。
   - 「支払い済みにする」は「確定済み」の請求書にだけ表示されます。
4. 支払い済みから3日たつと、講師用リンクでは口座番号が下4桁だけの表示になります（理事がログイン中に開いた場合は全部表示）。

### 3-5. 振込先一覧を印刷する
1. トップの「支払い待ちタスク」→「振込担当者用に一括印刷」。
2. 「印刷する」を押し、印刷画面で用紙の向きを選ぶ。
   - 縦向き：1件の請求書が3行で表示される
   - 横向き：1件の請求書が2行で表示される
3. どちらの向きでも、講座名・講師名・支払予定日・金融機関・支店名・口座種別・口座番号・口座名義・振込金額がすべて表示され、最後に合計（件数と金額）が出る。
4. 「PDFに保存」を選べば、PDFとして振込担当者に渡せる。

### 3-6. 講師用請求書を印刷する（紙で保管する場合）
1. 請求書管理簿の「確認・印刷」、またはトップの支払い待ちタスクの行を押して、講師用請求書ページを開く。
2. 確定済みなら「確定内容を印刷 / PDF保存」、未確定なら「印刷 / PDF保存」を押す。
3. A4縦・2ページで印刷される（1ページ目：概要・謝礼・機材、2ページ目：講師記入欄・署名）。文字はすべて黒で印刷される。
   - 印刷画面の「余白」は「デフォルト」のままにする。「倍率」を変えたり余白を大きくしたりすると3ページになることがある。

### 3-7. 講師に講座資料を提出してもらう
1. 資料庫を開き、講座の「資料を管理」を押す。
2. 「講師用リンク」の「コピー」を押し、案内文とリンクを講師に送る（講座ごとに1つ。発行手続きは不要）。
3. 講師が提出した資料は、資料庫の同じ画面に「講師」として表示される。
- 講師は自分で提出した資料を削除できません。誤って提出された資料は、理事が資料庫で削除します。

### 3-8. 講座の準備状況を確認・更新する
1. 講座準備進捗確認を開くと、講座ごとに8段階（企画決定→講師関係→募集準備→募集開始→申込管理→開催準備→開催→終了処理）の進捗バーが出る。
2. 段階の丸印を押すと中身が開き、手動の項目はチェックを付けるだけで保存される。
3. 赤の「！」は、目安の時期を過ぎても終わっていない段階（滞留）。ページ上部の「⚠ 目安を過ぎて止まっている講座があります」にまとめて表示される。

### 3-9. 参加者募集フォーム・講師資料PDF・理事資料が「ない」講座の場合
講座によっては、参加者募集フォームを使わない、講師資料PDFがない、理事側の資料がない、ということがあります。この場合は「不要」にチェックを付けると、その項目が済んだ扱いになり、滞留（赤の！）になりません。

1. 講座準備進捗確認で、該当する段階の丸印を押して中身を開く。
   - 参加者募集フォーム → 「3 募集準備」
   - 講師資料PDF・理事資料 → 「6 開催準備」
2. それぞれの項目のすぐ下にある次のチェックを付ける。
   - 「参加者募集フォームは使わない（不要）」…3 募集準備が完了扱いになり、申込数の欄は「不要」と表示される
   - 「講師資料PDFはない（不要）」…6 開催準備の講師資料PDFが完了扱いになる。備品チェック表の欄は「不要」と表示される
   - 「理事資料はない（不要）」…資料庫の件数表示が「理事 不要」になる（理事資料は、もともと完了の判定には使っていない）
3. 後からフォームや資料を登録することになったら、チェックを外せば元に戻る。

### 3-10. 月次報告書を出す（ベータ版）
1. 月次報告書を開き、月度を選ぶ。
2. 自分の担当科のカードを押し、報告者・直近の講座開催・その他報告・課題・改善点・添付ファイルを入力する。
3. 途中なら「下書き保存」、完成したら「提出する」。
4. 役員会の日程は「役員会の設定」で登録する。提出期限は、その月度以降の最初の役員会の2日前。
5. 提出が揃ったら「月次PDF作成」で1本のPDFにまとめる（提出済みの報告書だけが対象）。

### 3-11. Instagramの投稿文を作る（ベータ版）
1. SNS文章作成＆履歴を開き、「＋ 投稿文を作成」。
2. 講座と種類（募集告知／開催前リマインド／開催報告）を選ぶと、雛形から投稿文が作られる。
3. 内容を直して「投稿文をコピー」→ Instagramアプリに貼り付けて投稿する。
4. ステータス（下書き／投稿予定／投稿済み）を選んで保存する。
5. 投稿用の正方形画像は、「講座案内PDFから画像を作る」で作れる。

## 4. 困ったとき（よくある質問）

### ログイン・表示
**Q. ログイン画面が真っ白のまま進まない。**
A. LINEなどのアプリの中でリンクを開いている可能性があります。Androidではログイン画面の「LINEなどのアプリ内で開いている場合はこちら（Chromeで開く）」を押してください。iPhoneでは、リンクを長押しして「ブラウザで開く」（Safari）を選んでください。

**Q. 「このGoogleアカウントは登録されていません」と表示される。**
A. 名簿（AllowedAccounts）に、そのGoogleアカウントのメールアドレスが登録されていません。別のGoogleアカウントでログインしていないか確認し、それでもだめなら管理者に登録を依頼してください。登録後、反映まで最大5分かかります。

**Q. 「メールアドレスの確認が済んでいないためログインできません」と表示される。**
A. Googleアカウントを作ったときに届いた確認メールのリンクを、まだ押していません。Googleからのメールを探してリンクを押し、もう一度ログインしてください。

**Q. ログインできない人がいる。どこを見ればよい？（管理者向け）**
A. 本人にもう一度ログインを試してもらい、スプレッドシートの「ActivityLog」シートの一番下を見てください。「login_denied」の行があれば、そのメールアドレスが名簿に登録されていません（別アカウントでのログインや、登録アドレスの打ち間違い）。「login_token_rejected」の行があれば、内容の欄に理由が書かれています。何も記録がなければ、ポータルまで届いていない（LINEのアプリ内ブラウザなど）ので、本人の画面の表示を確認してください。

**Q. 請求書管理簿を開くと「権限が設定されていません」と表示される。**
A. 名簿の「請求書アクセス」欄に印がありません。必要な場合は管理者に依頼してください。

**Q. 作業中に「ログインの有効期限が切れました」と出た。**
A. ログインは最大6時間有効です。もう一度ログインすれば、そのまま続けられます。

**Q. トップ画面の内容が古いまま。**
A. トップ画面は、前回の内容をすぐに表示してから裏で最新の情報を取り直します（取得中は左下に「最新の情報を取得中…」と表示）。少し待つか、スマホでは画面の一番上で下に引っ張って更新してください。

**Q. 「他の方の保存処理と重なり混み合っています」と表示された。**
A. 別の理事が同時に保存していました。少し待ってから、もう一度保存してください。

**Q. 「サーバー側のプログラムが古いままの可能性があります」と表示された。**
A. 管理者向けのメッセージです。GASのコードを最新にして「新しいバージョン」で再デプロイする必要があります。管理者に連絡してください。

### 請求書
**Q. 講師から「確定した内容を直したい」と言われた。**
A. 3-3の「差し戻し」を行ってください。

**Q. 「支払い済みにする」ボタンがない。**
A. 講師がまだ確定していない（「作成済み」の）請求書です。講師の確定を待ってください。

**Q. 講師用リンクを開くと「このリンクは無効か、期限切れの可能性があります」と出る。**
A. リンクの一部が欠けているか、請求書が見つかりません。請求書管理簿の「その他の操作」→「案内文とリンクをコピー」でリンクをコピーし直して送ってください。「一時的に読み込めませんでした」の場合は、通信の問題なので時間をおいて開き直してください。

**Q. 講師から「振込先が＊＊＊になっていて見えない」と言われた。**
A. 支払い済みから3日たつと、個人情報保護のため振込先を伏せて表示します（仕様です）。理事がポータルにログインしたまま開くと、すべて表示されます。

**Q. 請求書が多くて見つけにくい。**
A. 請求書管理簿は、未完了（作成済み・確定済み）が上、支払い済み・取消が下に並び、10件ごとにページが分かれています。表の下のページ番号で移動してください。

**Q. 講座を削除しようとしたらできない。**
A. 請求書が紐づいている講座は削除できません。先に請求書を「取消」してください。

**Q. 取消した請求書を元に戻したい。**
A. 取消は元に戻せません。新しく請求書を作り直してください（取消した請求書は記録として一覧に残ります）。

### 講座準備進捗確認
**Q. 赤の「！」（滞留）が消えない。**
A. 段階の中身を開き、未チェックの項目を確認してください。フォームや資料が「ない」講座なら、3-9の「不要」にチェックを付けます。開催日を過ぎた講座は、ステータスを「実施済み」にすると、開催前の段階は滞留扱いになりません。

**Q. 申込数が表示されない。**
A. 講座進捗ページの「⑤ 参加者募集フォーム」に回答用スプレッドシートのURLが登録されていないか、そのスプレッドシートがシステムのGoogleアカウントに共有されていません。フォームを使わない講座なら「不要」にチェックを付けてください。

### カレンダー
**Q. 「直近の予定」は見えるのに、「カレンダーで見る」や「自分のGoogleカレンダーに追加する」で予定が出ない。**
A. ポータルの「直近の予定」の一覧は誰でも見られますが、2つのリンクは自分のGoogleアカウントでカレンダーを開くため、研究会のカレンダーが自分に共有されている必要があります。管理者に共有を依頼してください。

### ファイル・資料
**Q. Googleドライブのファイルを開くと「アクセス権が必要です」と出る。**
A. 名簿に登録したGoogleアカウントでブラウザにログインしているか確認してください（個人用の別アカウントでログインしていると開けません）。講師を含め、名簿にない人は開けません。

**Q. PDFや資料がアップロードできない。**
A. 大きさの上限を確認してください。講座案内PDF・講師資料PDFは15MBまで、資料庫・講師の資料提出は20MBまでです。講師の資料提出は、PDF・Word・Excel・PowerPoint・画像・動画・音声・テキスト・ZIPなど決まった形式だけ受け付けます。

**Q. 講師が「提出済みの資料を開けない」と言っている。**
A. 仕様です。講師のページには提出した資料のファイル名だけが表示され、ファイルは理事だけが開けます。

### 印刷
**Q. 振込先一覧を印刷すると白紙のページが入る・右側が切れる。**
A. 2026-09-27に直しました。直っていない場合は、ブラウザで画面を再読み込み（最新のページに更新）してから印刷してください。

**Q. 講師用請求書の印刷が3ページになる。**
A. 印刷画面の「余白」を「デフォルト」、「倍率」を「100」（既定）にしてください。

A. 仕様です。画像以外の添付ファイルは、PDFの中ではリンクとして載ります。

## 6. 用語集

| 用語 | 意味 |
|---|---|
| 請書兼請求書 | 講師が講演の依頼を引き受ける「請書」と、謝礼の「請求書」を1枚にしたもの。理事が作成し、講師が振込先などを入力して確定する |
| 作成済み | 理事が請求書を作成し、講師の確定を待っている状態 |
| 確定済み | 講師が内容を確定した状態。支払い待ち |
| 支払い済み | 振込が済んだ状態 |
| 取消 | 取り消した請求書。記録として一覧に残り、元には戻せない |
| 差し戻し | 確定済みの請求書を作成済みに戻し、講師に修正してもらうこと |
| 講師用リンク | 講師がログインなしで開ける専用のURL。請求書ごと（請求書管理簿）、講座ごと（資料庫）にある |
| 講座の時間 | 受講者向けの講座の開始・終了時刻 |
| 講師依頼時間 | 講師に来てもらう時間（集合・打ち合わせを含む）。空欄なら講座の時間と同じ |
| 8段階 | 講座準備の流れ：企画決定→講師関係→募集準備→募集開始→申込管理→開催準備→開催→終了処理 |
| 目安の時期 | 各段階を終えておきたい日。開催日からの日数で決まる（Settingsシートで変更可） |
| 滞留（赤の！） | 目安の時期を過ぎても終わっていない段階 |
| 不要 | その講座では使わない項目（参加者募集フォーム・講師資料PDF・理事資料）。チェックすると済んだ扱いになる |
| 講師資料PDF | 講座進捗ページの「④ 講師資料PDF」に登録する、講師から預かった資料（1講座1ファイル）。資料庫とは別 |
| 資料庫 | 講座ごとの資料をまとめて保管する場所。理事のアップロードと講師の提出の両方が入る |
| 名簿（AllowedAccounts） | ログインできる理事のGoogleアカウントの一覧（スプレッドシートのシート） |
| 請求書アクセス | 名簿の欄。印がある理事だけが請求書関連の機能を使える |
| ベータ版 | 調整中の機能。表示や動作が変わることがある（月次報告書・SNS文章作成＆履歴） |
| ActivityLog | 操作の記録（スプレッドシートのシート）。データの変更と、断ったログインが記録される |

## 7. 管理者向け：よくある設定作業

| やりたいこと | 方法 |
|---|---|
| 理事を追加する／外す | スプレッドシートの「AllowedAccounts」シートに行を追加／削除。すぐ反映したいときはApps Scriptで「clearAccountCache」を実行 |
| 請求書を使える理事を変える | 「AllowedAccounts」シートのE列「請求書アクセス」に印（例：○）を付ける／消す |
| 担当科を追加する | 「Departments」シートに行を追加（スキルアップコースならB列に印） |
| 備品チェックの項目を変える | 「PulldownOptions」シートの区分「講座準備チェック項目」の行を追加・編集・削除 |
| 開催場所・研修形式・資料区分の選択肢を変える | 「PulldownOptions」シートの該当する区分の行を編集 |
| 8段階の目安の時期を変える | 「Settings」シートの phase〜OffsetDays の値を変更（マイナス＝開催前の日数） |
| 請求書アラートの基準を変える | 「Settings」シートの createAlertDays（未作成）・unrespondedAlertDays（講師未返信）・paymentWarningDays（支払期限接近） |
| SNSの雛形を変える | 「SnsTemplates」シートの「本文」「ハッシュタグ」を書き換える |
| システムを更新する | GASのコードを貼り替え →（列が増える更新のときだけ）initializeSpreadsheet を実行 →「デプロイを管理」で「新しいバージョン」として再デプロイ。画面のファイルはGitHubにアップロード |
