# 理事ポータル 機能説明書

2026-10-09 更新（2026-09-27版からの更新。変更点は末尾の「更新履歴」を参照）

この説明書は最新版です。古い版（2026-09-26版、2026-09-27版など）と内容が異なる場合は、この版が正しい内容です。

## 概要

理事ポータルは、NPO法人日本繊維商品めんてなんす研究会の理事向け業務システムです。GitHub Pagesで公開されたフロントエンド（HTML/JavaScript）と、Google Apps Script（GAS）＋Googleスプレッドシートのバックエンドで構成されています。講座の準備進捗管理（全講座を8段階で横断的に確認）、講師への請書兼請求書の発行・確認・印刷、担当科ごとの月次報告書の作成とPDF化、講座資料の保管・管理、Instagram投稿文の作成と投稿履歴の管理を一元的に行えます。

システムは8つの画面で構成されます。

| ページ | ファイル名 | 用途 |
| --- | --- | --- |
| 理事ポータル | index.html | ログイン後のトップ画面。ダッシュボード、講座一覧、講座ごとの進捗管理を行う |
| 講座準備進捗確認 | course-progress.html | 全講座の準備状況を8段階で一覧表示し、チェックを付けて更新する。目安を過ぎて止まっている講座を警告する |
| 請求書管理簿 | invoice-ledger.html | 請書兼請求書の新規作成・編集・一覧確認・講師用リンクの発行・支払い管理・差し戻しを行う（請求書アクセス権限を持つ理事のみ） |
| 講師用請求書 | invoice-lecturer.html | 講師本人が銀行口座情報などを入力し、内容を確定・印刷するページ（Googleログイン不要） |
| 月次報告書（ベータ版） | reports.html | 担当科ごとの月次報告書を作成・提出し、提出済みの報告書をまとめて1つのPDFにする |
| 資料庫 | materials.html | 講座ごとの資料をアップロード・管理する。講座ごとの資料件数を一覧で確認できる（管理簿） |
| SNS文章作成＆履歴（ベータ版） | sns.html | 講座のInstagram投稿文（募集告知・開催前リマインド・開催報告）を雛形から作成し、投稿予定・投稿済みの履歴を管理する |
| 講師用資料提出 | materials-lecturer.html | 講師本人が講座で使う資料を提出するページ（Googleログイン不要） |

「ベータ版」は、現在調整中の機能です。表示や動作が変わることがあります。

8画面とも同じGoogle Apps ScriptのWebアプリをバックエンドとして呼び出し、データはすべてGoogleスプレッドシートに、ファイルはGoogleドライブに保存されます。

主なページ間の連携は次の通りです。

* 理事ポータルの講座進捗ページ→「請求書を作成する」→請求書管理簿が開き、講座情報が自動入力された状態で新規作成画面が開く
* 理事ポータルの講座進捗ページ→「請求書を開く」→請求書管理簿が開き、該当請求書の編集画面が自動的に開く（確定済み・支払い済みの請求書は、うっかり書き換えないよう編集画面は開かず、一覧のその請求書の行が水色で示される）
* 請求書管理簿で発行した講師用リンクを講師にメールなどで送付し、講師はログインなしで内容確認・入力・確定・印刷を行う
* 資料庫で講座ごとの講師用リンクをコピーして講師に送付し、講師はログインなしで資料を提出する
* 月次報告書の「直近の講座開催」では、講座一覧に登録された講座を選ぶと、開催日と参加者数が自動入力される
* ダッシュボードの「報告書未提出」カードから月次報告書のページへ移動できる
* ダッシュボードの「進捗状況」カードから講座準備進捗確認のページへ移動できる
* 講座準備進捗確認の「講座進捗を開く →」から、理事ポータルのその講座の講座進捗ページが直接開く

ログイン状態は同一タブ内で、理事ポータル・講座準備進捗確認・請求書管理簿・月次報告書・資料庫・SNS文章作成＆履歴の間で共有されます（ページを移動しても再ログインは不要）。

**表示を速くするための仕組み** 同じタブで理事ポータルのトップページや講座準備進捗確認を開き直したとき（他のページから戻ったときなど）は、前回読み込んだ内容をすぐに表示し、裏で最新の情報を取得して、変わっていれば自動で表示を更新します。最新の情報を取得している間は、「最新の情報を取得中…」と表示されます（トップページは画面の左下）。前回の内容はタブを閉じるかログアウトすると消えます。また、通信が一時的に失敗した場合、読み込みは1回だけ自動でやり直します。

## 画面共通の機能

**文字サイズの切り替え** 各画面の上部に「文字サイズ　標準／大／特大」の切り替えボタンがあります。選んだ文字サイズはそのブラウザに記憶され、他の画面にも共通して適用されます。講師用のページ（講師用請求書・講師用資料提出）にも同じボタンがあります。

**スマホ表示** すべての画面がスマホの画面幅に合わせて表示されます。表が横に長くなる画面（資料庫の一覧、請求書管理簿の一覧など）は、スマホでは1件ずつのカード表示に切り替わります。理事ポータルと月次報告書では、ページの一番上で画面を下に引っ張ると最新の情報に更新されます。

**画面切り替えバー** ログインが必要な6つの画面（トップ・準備進捗・請求書・月次報告書・資料庫・SNS）では、ヘッダーのすぐ下に画面切り替えバーがあり、トップに戻らなくても、どの画面からでも別の画面へ直接移動できます。今いる画面は枠付きで表示されます。スマホではバーを横にスクロールできます。

**講座ごとのリンク（この講座の：）** 次の場所には「この講座の：講座進捗 › 準備進捗 › 請求書 › 資料庫 › SNS ›」というリンクがあり、同じ講座の別の画面へ直接移動できます（今いる画面のリンクは表示されません）。

| 場所 | 移動先での表示 |
| --- | --- |
| 講座準備進捗確認の各講座のカード | ― |
| 理事ポータルの講座進捗ページ（ボタンの下。入力途中の内容が消えないよう新しいタブで開く） | ― |
| 資料庫の講座ごとの資料画面 | ― |
| （移動先）講座進捗 | その講座の講座進捗ページが開く |
| （移動先）準備進捗 | その講座のカードまで移動して強調表示する |
| （移動先）請求書 | その講座の請求書（取消以外で最新のもの）の編集画面が開く（確定済み・支払い済みの請求書は、編集画面は開かず、一覧のその行が水色で示される。内容は「確認・印刷」、支払いや差し戻しは「その他の操作」から）。まだ無ければ、講座の情報が入った新規作成の画面が開く（請求書アクセスのある理事のみ） |
| （移動先）資料庫 | その講座の資料画面が開く |
| （移動先）SNS | 講座別の表で、その講座の行まで移動して強調表示する |

**操作ガイド（NotebookLM）** 理事ポータルのトップ画面の一番上に「操作に困ったら『理事ポータル 操作ガイド』」の欄があります。押すとNotebookLM（理事ポータル ヘルプデスク）が新しいタブで開き、使い方を文章で質問できます（例：「講師に請求書のリンクを送るには？」）。

## ログイン・認証

理事ポータル・講座準備進捗確認・請求書管理簿・月次報告書・資料庫・SNS文章作成＆履歴は、あらかじめ登録されたGoogleアカウントでのログインが必要です。ログイン画面には「あらかじめ登録された理事のみ利用できます。」という案内とともに、標準の「Googleでログイン」ボタンが表示されます。

**ログインできないときに表示されるメッセージ**

| 表示 | 意味と対処 |
| --- | --- |
| 「このGoogleアカウントは登録されていません。事務局(担当理事)にご連絡ください。」 | 名簿（AllowedAccounts）に、ログインに使ったGoogleアカウントのメールアドレスが登録されていない。別のアカウントでログインしていないか確認する。登録が必要な場合は管理者に依頼する |
| 「このGoogleアカウントは、メールアドレスの確認が済んでいないためログインできません。…」 | Googleアカウントのメールアドレスが未確認。Googleから届いた確認メールのリンクを押してから、もう一度ログインする |
| 「ログインの設定に不整合があります（CLIENT_ID）。管理者にご連絡ください。」 | システム側の設定の問題。管理者に連絡する |
| 「ログインに失敗しました。時間をおいて再度お試しください。」 | 一時的な問題。少し待ってから試す |
| 「サーバーに接続できませんでした。…」 | 通信の問題。通信環境を確認する |
| 画面が真っ白／ログインボタンが出ない | LINEなどのアプリ内ブラウザで開いている可能性（後述） |

請求書管理簿については、ログインできても請求書アクセス権限（後述）がない場合、「このGoogleアカウントには、請求書管理簿を利用する権限が設定されていません。必要な場合は事務局(管理担当理事)にご連絡ください。」という権限なし画面が表示されます。

**アクセス権限の考え方**

* 理事ポータルの基本機能（講座管理など）、講座準備進捗確認、月次報告書、資料庫、SNS文章作成＆履歴は、名簿に登録されたメールアドレスであれば誰でも利用できます。
* 請求書関連の機能（作成・編集・一覧・取消・支払い済み処理・差し戻しなど）は、名簿の「請求書アクセス」欄に印がある理事のみ利用できます。
* 講師本人がアクセスする「講師用請求書」と「講師用資料提出」のページは、Googleログイン自体が不要です。請求書ごと・講座ごとに割り当てられたランダムなID（推測困難なURL）だけで保護されており、そのIDを知っている人だけが該当ページを閲覧・入力できます。

**ログインの有効時間と、名簿の変更が反映されるまでの時間**

* 一度ログインすると、同じブラウザなら別のタブ・別の画面でも、最大6時間はログインしたまま使えます（ログアウトすると、そのブラウザの全タブでログアウトします）。有効時間が過ぎると、次の操作のときに「ログインの有効期限が切れました。お手数ですが、もう一度ログインしてください。」と表示され、ログイン画面に戻ります。ログインし直せば、そのまま作業を続けられます。
* 名簿（AllowedAccounts）で登録を追加・削除した場合や、請求書アクセスの印を付け外しした場合、画面に反映されるまで最大5分かかります。すぐに反映したい場合は、管理者がApps Scriptのエディタで「clearAccountCache」を実行します。

**ログインを断った記録** 名簿にないアカウントでログインしようとした場合、操作の記録（ActivityLog）に「login_denied」として、日時・ログインしようとしたメールアドレス・Googleアカウント名が残ります（同じ人は10分に1回）。Googleのログイン情報の確認で断った場合（メールアドレス未確認など）は「login_token_rejected」として理由と一緒に残ります。請求書アクセスのない人が請求書機能を開いた場合は「invoice_access_denied」として残ります。「ログインできない」と言われたら、管理者はこの記録のメールアドレスと名簿を見比べると、アカウント違いや打ち間違いがすぐ分かります。普通にログインして閲覧しただけでは記録は残りません。

**LINEなどのアプリ内ブラウザで開いた場合の注意点**

理事の方にポータルのURLをLINEなどで共有すると、LINEアプリ内蔵のブラウザ（アプリ内ブラウザ）で開かれることがあり、Googleログインの仕組みがアプリ内ブラウザでは正しく動作しない場合があります。この場合、画面が真っ白なまま何も表示されない、という症状が出ることが確認されています。

対策として、ログインボタンの読み込みが8秒以上かかった場合に、エラーメッセージと「ページを再読み込み」ボタンを表示するようにしています。また、Android端末では、ログイン画面に次のリンクが自動的に表示されます。

> 「LINEなどのアプリ内で開いている場合はこちら（Chromeで開く）」

このリンクを押すと、Chromeブラウザで同じページを開き直すことができ、多くの場合ログイン不具合を回避できます。iOS端末ではこのリンクは表示されません。iOSやAndroidでこのリンクでも解決しない場合は、リンクを長押しして「他のアプリで開く」「ブラウザで開く」を選ぶか、LINEアプリの設定で「リンクをデフォルトのブラウザで開く」をオンにする方法も有効です。

## ダッシュボード（理事ポータルのトップ画面）

ログイン後の理事ポータルには、上から順に、操作ガイドへの案内、6種類の情報カード、メニュー、講座一覧が表示されます。

**直近の予定（Googleカレンダー）** 研究会の共有Googleカレンダーから、60日以内の予定を取得して表示します。この一覧は、カレンダーを個人的に共有していない理事にも表示されます。予定がない場合は「直近の予定はありません。」、カレンダーの設定に問題がある場合は「カレンダーを表示できません。管理者にカレンダーの共有設定をご確認いただいてください。」と表示されます。講座や役員会を登録すると、このカレンダーにも自動で予定が登録されます（後述）。

* 見出しの右の「カレンダーで見る ↗」を押すと、Googleカレンダーの月表示が新しいタブで開きます。
* 一覧の下の「＋ 自分のGoogleカレンダーに追加する」を押すと、自分のGoogleカレンダーに研究会のカレンダーを追加できます。一度追加すると、スマホのカレンダーアプリにも研究会の予定が表示されます。
* この2つのリンクで予定が表示されない場合は、研究会のカレンダーが自分のGoogleアカウントに共有されていません。管理者に共有を依頼してください。

**支払い待ちタスク** 支払いがまだ完了していない請求書（ステータスが「作成済み」または「確定済み」のもの）を、支払予定日が近い順にすべて表示します。各行には講座名、講師名、実際の振込金額（税・源泉徴収・交通費等を反映した最終額）、ステータス、支払期日のバッジ（超過している場合は赤字で「（超過）」表示）が並びます。確定済みの請求書には「支払い済みにする」ボタンが表示され、作成済みの請求書には「講師確認待ちのため支払い操作はできません」と表示されます。行をクリックすると、その請求書の確認・印刷ページ（講師用請求書ページ）が新しいタブで開きます。

見出しの右側には「振込担当者用に一括印刷」ボタンがあり、これを押すと支払い待ちの全請求書をまとめた印刷用の一覧が表示されます（詳細は後述の「印刷・出力機能」を参照）。

**最近のコメント** 講座進捗ページに投稿されたコメントを、全講座から新しい順に最大8件表示します。各コメントには講座名・投稿者名・投稿日時・本文が表示され、クリックするとその講座の講座進捗ページが開きます。コメントがない場合は「まだコメントはありません。」と表示されます。

**お知らせ（tema.jp）** 研究会の公式サイト（tema.jp）のトップページにある「TeMAの最新情報はこちら」の欄から、講座のお知らせ記事を最大6件取得して、タイトルをリンクとして表示します。クリックすると記事が新しいタブで開きます。見出しの右側の「もっと見る」からは講座一覧ページ（tema.jp/new_course_list/）が開きます。取得した内容は1時間保存して使い回します。サイトから取得できなかった場合は「最新のお知らせを tema.jp で見る」というリンクだけが表示されます。

**報告書未提出** 今月度の月次報告書がまだ提出されていない担当科を表示します。提出期限（役員会の2日前）が設定されていれば「提出期限：YYYY-MM-DD」を表示し、期限を過ぎている場合は赤字で「（期限超過）」と表示されます。すべての担当科が提出済みの場合は「今月度、未提出の科はありません。」と表示されます。見出しの右側の「月次報告書へ」から月次報告書のページに移動できます。

**進捗状況** 直近の講座の準備状況を、講座準備進捗確認と同じ8段階（企画決定・講師関係・募集準備・募集開始・申込管理・開催準備・開催・終了処理）の一覧表で表示するワイドカードです。判定の基準は講座準備進捗確認と共通です（後述の「講座準備進捗確認」を参照）。

* 対象は、中止以外で、開催日が30日前から120日後までの講座（開催日未定の講座を含む）。開催日の早い順に最大8件を表示し、9件以上ある場合は下に「他◯件を講座準備進捗確認で見る →」というリンクが表示される
* 列は「講座名／開催日／1〜8の各段階／申込／資料」。各段階は ✓（完了、緑）、！（目安を過ぎて未完了、赤）、●（未完了）、－（記録なし。開催済みの講座で開催より前の段階が未チェックのもの）で表示される。マークにカーソルを合わせると、段階名・状態・目安の日付が表示される
* 講座名の下には、請求書のアラート（「講師側未返信」「支払期限接近」「支払期限超過」）が表示される
* 申込の列には、参加者募集フォームを登録済みの講座の申込件数が表示される。件数を押すと回答用スプレッドシートが開く。参加者募集フォームを「不要」に設定した講座は「不要」と表示される
* 資料の列には、資料庫の資料件数（理事・講師の合計）が表示される
* 行を押すと、その講座の「講座進捗」ページが開く
* スマホでは表の部分だけを横にスクロールでき、講座名の列は固定されたまま表示される
* 見出しの右側の「講座準備進捗確認へ」から、全講座を対象にした講座準備進捗確認のページに移動できる

請求書アクセス権限のない理事にも表示されます（請求書は状態と支払予定日だけを判定に使い、金額などは表示しません）。

**メニュー** 「メニュー」の見出しの下に、次の5つのメニューが機能ごとに色分けされて並びます。カードにマウスを乗せると、色が少し濃くなります。

| 月次報告書（ベータ版） | オレンジ | 月次報告書 |
| 資料庫 | 紫 | 資料庫 |
| SNS文章作成＆履歴（ベータ版） | ピンク | SNS文章作成＆履歴 |

パソコンでは5つが横一列に並び、画面幅が狭くなると3列・2列・1列に折り返します。

## 講座管理（講座一覧・講座進捗ページ）

**講座一覧** 「講座一覧」の見出しの下に、登録済みの講座がカード形式で並びます。講座案内PDFを登録している講座では、カードにPDFの1ページ目の縮小画像（サムネイル）が表示されます。PDFを登録していない講座では📄アイコンが表示されます。

「＋ 新しい講座を追加」ボタンから、講座名・開催日・開催場所・講座の開始／終了時刻・講師依頼時間（開始／終了）・担当理事・担当科・研修形式・ステータスを入力して新規講座を登録できます。カードをクリックすると、その講座の「講座進捗」ページが開きます。

**講座の時間と講師依頼時間** 講座には、2種類の時間を登録できます。

| 時間 | 意味 | 使われる場所 |
| --- | --- | --- |
| 講座の開始時刻・終了時刻 | 受講者向けの講座の時間 | 講座一覧、講座進捗ページ、Googleカレンダー、WordPress用案内文、SNS投稿文、請書兼請求書の「開催日時」、講師用資料提出ページの「開催日時」 |
| 講師依頼時間（開始・終了） | 講師の方にお願いする時間（集合・打ち合わせ等を含む） | 講座進捗ページ、請書兼請求書の「講師依頼時間」（自動入力）、講師用資料提出ページの「講師依頼時間」、Googleカレンダーの予定の説明文 |

講師依頼時間は任意の項目で、空欄の場合は講座の時間と同じ扱いになります。講座進捗ページでは「講師依頼時間：講座の時間と同じ」と表示されます。

**Googleカレンダーへの自動登録** 講座を追加・編集・削除すると、ダッシュボードに表示している共有Googleカレンダーにも、その講座の予定が講座の時間で自動で登録・更新・削除されます。講師依頼時間が登録されている場合は、予定の説明文に「講師依頼時間：◯〜◯」と書き加えられます。

**講座進捗ページ（講座のトップページ）** 各講座の中心画面です。開くと、講座名・開催日（講座の時間）・講師依頼時間・開催場所・担当理事（担当科）・研修形式・ステータスが上部にまとまって表示され、その下に次の3つのボタンが並びます。

* **講座編集** — 講座の基本情報（日時・場所・担当理事など）を編集する
* **PDF機能** — 講座案内PDFのアップロード・差し替え・削除・サムネイル確認を行う（PDFは最大15MB）
* **プロンプト書き出し** — 講座案内文をWordPress用のHTMLとして作成するツールを開く。講座案内PDFの内容をAIに読み取らせて貼り付けると、案内文HTMLを自動生成・コピーできる（AIに渡すためのプロンプト例のコピー機能も含む）

さらに以下の6つのセクションが並びます。

1. **講師打ち合わせ** — 「打ち合わせ済み」チェックボックスと、打ち合わせメモを記入する欄
2. **請書兼請求書** — 紐づく請求書のステータス・講師名・振込金額・支払予定日のサマリーを表示。未作成の場合は「請求書を作成する」ボタンから請求書管理簿へ、作成済みの場合は「請求書を開く」リンクから該当請求書の編集画面へ（確定済み・支払い済みの場合は一覧のその行へ）、それぞれ新しいタブで移動できる
3. **講座準備（必要備品チェック）** — 受付名簿・会場看板・資料印刷など、準備すべき備品のチェックリスト。項目はスプレッドシートの「PulldownOptions」シートの「講座準備チェック項目」区分で自由に追加・編集できる
4. **講師資料PDF** — 講師から預かった資料PDF（最大15MB）をアップロード・閲覧・削除。1講座につき1ファイル。8段階の「6 開催準備」の判定に使われる（後述の「資料庫」とは別の仕組みで、連動していない）
5. **参加者募集フォーム** — 詳細は「参加者募集フォーム連携」を参照
6. **コメント** — 他の理事への申し送り事項などを投稿できる。投稿者名と日時付きで一覧表示され、ダッシュボードの「最近のコメント」にも表示される

ページ下部には「この講座を削除」「閉じる」「保存」ボタンがあります。請求書が紐づいている講座は削除できず、先に請求書を取り消す必要があります。

**講座案内PDFのサムネイルについて** 講座案内PDFをアップロードすると、PDFの1ページ目の縮小画像を取得して保存します。古い講座でサムネイルが表示されない場合は、管理者がApps Scriptで「refreshAllCourseThumbnails」を1回実行すると、まとめて取り直されます。

## 講座準備進捗確認

「講座準備進捗確認」は、全講座の準備状況を1つの画面で横断的に確認し、その場でチェックを付けて更新できるページです。ダッシュボードの「進捗状況」カードは直近の講座を最大8件だけ表示しますが、このページでは全講座を対象にでき、進捗バーの表示や段階ごとのチェックもできます。ログインした理事であれば誰でも利用できます。

**8段階の進捗** 講座の準備を次の8段階に分け、講座ごとに左から右へ並んだ進捗バーで表示します。

| 段階 | 完了の条件 | 判定 | 目安の時期（初期値） |
| --- | --- | --- | --- |
| 1 企画決定 | 開催日・開催場所・担当理事が登録されている | 自動 | 開催90日前 |
| 2 講師関係 | ①講師打ち合わせ済み、②請書兼請求書を送付（請求書を作成済み）、③講師から返信（請求書が確定済み） | ①は手動チェック、②③は自動 | 開催60日前 |
| 3 募集準備 | 講座案内PDFと参加者募集フォームが登録されている（フォームは「不要」にもできる） | 自動 | 開催45日前 |
| 4 募集開始 | 告知・募集を開始した | 手動チェック | 開催40日前 |
| 5 申込管理 | 申込を締め切り、参加者が確定した（現在の申込数も表示） | 手動チェック | 開催7日前 |
| 6 開催準備 | ④備品チェックリストの全項目と、講師資料PDFの登録（講師資料PDFは「不要」にもできる。資料庫の件数も表示） | チェックリストは手動、講師資料PDFは自動 | 開催3日前 |
| 7 開催 | ⑤講座のステータスが「実施済み」 | 手動チェック | 開催日当日 |
| 8 終了処理 | ⑥講師への支払いが済んだ、提出済みの月次報告書にその講座が記載されている | 自動 | 開催30日後 |

目安の時期は、スプレッドシートの「Settings」シートの値で変更できます（開催日からの日数。マイナスは開催前、プラスは開催後）。

「月次報告書に記載」は、提出済みの月次報告書の「直近の講座開催」に、同じ講座名（スペースの有無は無視）で記載されているかで判定します。報告書側と講座側の両方に開催日が入っている場合は、開催日も一致している必要があります。下書きの報告書は対象外です。

**「不要」の選択肢（参加者募集フォーム・講師資料PDF・理事資料）** 講座によっては、参加者募集フォームを使わない、講師資料PDFがない、理事側の資料がない、ということがあります。この場合は、段階の中身を開いて、該当する項目のすぐ下にある「不要」のチェックを付けます。その項目は済んだ扱いになり、滞留（赤の！）になりません。

| チェック | 場所 | 付けたときの動き |
| --- | --- | --- |
| 参加者募集フォームは使わない（不要） | 3 募集準備 | 募集準備のフォームの項目が完了扱いになる。申込数の欄は「不要」と表示される |
| 講師資料PDFはない（不要） | 6 開催準備 | 開催準備の講師資料PDFの項目が完了扱いになる。備品チェック表の講師資料PDFの欄は「不要」と表示される |
| 理事資料はない（不要） | 6 開催準備 | 資料庫の件数の表示が「理事 不要」になる（理事資料は、もともと完了の判定には使っていない） |

同じように、次の2つも設定できます。

| チェック | 場所 | 付けたときの動き |
| --- | --- | --- |
| 講座案内PDFはない（不要） | 3 募集準備 | 講座案内PDFの項目が完了扱いになる |
| 講師がいない講座（勉強会など） | 2 講師関係 | 講師打ち合わせ・請書兼請求書・講師資料PDF・講師への支払いの項目がすべて完了扱いになる。講座のカードに「講師なし」と表示され、請求書管理簿の「請求書が未作成の講座があります」にも出なくなる |

「不要」のチェックには、チェックを付けた日付が記録されます。後からフォームや資料を登録することになったら、チェックを外せば元に戻ります。「不要」のチェックそのものは、段階の完了の判定には含まれません。

**進捗バーの見方** 各段階は丸印で表示され、下に段階名と目安の日付が並びます。

* 緑の✓ — 完了
* 青い枠 — いま取り組む段階（まだ完了していない最初の段階）
* 赤の！ — 目安の日付を過ぎても完了していない（滞留）
* グレー — これから
* 点線のグレー — 記録なし。開催済み（ステータスが「実施済み」）の講座で、開催より前の段階にチェックが付いていないもの。滞留扱いにしない

開催日が未定の講座は目安の時期を計算できないため、日付は「－」と表示され、滞留の判定も行いません。中止の講座は薄く表示され、滞留の判定を行いません。

**段階の中身とチェック** 段階の丸印を押すと、その段階の中身が下に開きます。手動の項目はチェックボックスになっており、チェックを付けたり外したりするとすぐに保存されます（「保存しました」と表示されます）。自動判定の項目は「（自動判定）」と表示され、どこで登録すれば完了になるかの案内が出ます。目安の日付と、過ぎている場合は何日超過しているかも表示されます。

* 「募集開始」「申込締切・参加者確定」のチェックは、チェックを付けた日付が記録されます
* 「⑤ 講座を開催した」にチェックを付けると、講座のステータスが「実施済み」になります。外すと「実施予定」（選択肢にない場合は「準備中」）に戻ります
* 備品チェックリストや①講師打ち合わせのチェックは、講座進捗ページのチェックと同じデータです。どちらで付けても反映されます

**講座ごとの表示** 各講座の上部には、講座名、開催日、担当科、担当理事と、ステータス、請求書のアラート（講師側未返信・支払期限接近・支払期限超過）、申込数（会場／ZOOM。フォーム不要の講座は「申込フォーム 不要」）、資料庫の資料件数（理事・講師）が並びます。「講座進捗を開く →」を押すと、理事ポータルのその講座の講座進捗ページが直接開きます。

**滞留アラート** ページ上部に「⚠ 目安を過ぎて止まっている講座があります（◯件）」として、滞留している段階がある講座をまとめて表示します。対象は、中止以外で、開催日が90日前以降の講座です。5件を超える場合は「他◯件を表示」で残りを開けます。アラートを押すと、その講座の進捗バーまで移動し、滞留している段階の中身が開きます。

**絞り込み** 「期間」（今後の講座＋直近30日／今後の講座のみ／開催済み（過去の講座）／すべて）、「担当科」、「担当理事」、「講座名で検索」で表示する講座を絞り込めます。中止の講座は、「中止の講座も表示」にチェックを付けたときだけ表示されます。

**表示の切り替え** 「進捗バー」「一覧表」「備品チェック表」の3つの表示を切り替えられます。

* 進捗バー — 講座ごとのカードに8段階の進捗バーを表示する（初期表示）
* 一覧表 — 講座を行、8段階を列にした表。申込数（フォーム不要の講座は「不要」）と資料件数の列もある
* 備品チェック表 — 講座を行、備品チェックリストの項目を列にした表。表の中で直接チェックを付けられる。講師資料PDFの有無（不要の講座は「不要」）と、開催準備の段階の状態・目安の日付も表示する

**請求書アクセス権限がない理事の場合** ②③⑥の判定には請求書の状態が必要なため、請求書アクセス権限のない理事にも、請求書の「ステータス」と「支払予定日」だけを表示に使います。金額や講師の口座情報などは表示されません。

## SNS文章作成＆履歴（ベータ版）

「SNS文章作成＆履歴」は、講座のInstagram投稿文（キャプション）を作成し、いつ何を投稿したか・投稿する予定かを記録するページです。講座ごとに「募集告知」「開催前リマインド」「開催報告」の3種類の投稿文を作れます。ログインした理事であれば誰でも利用できます。現在はベータ版（調整中）で、今後AIを使った投稿文の作成機能を追加する予定です。

**投稿文の作り方** 投稿文は、スプレッドシートの「SnsTemplates」シートにある雛形（種類ごとに1行）に、講座の情報を差し込んで作ります。現在はAIは使わず、雛形どおりの文章が作られます。

1. 「＋ 投稿文を作成」、または講座別の表の「＋ 作成」を押す
2. 講座と種類を選ぶと、投稿文の下書きが自動で作られる
3. 内容を確認して手直しする。文字数（上限2,200文字）とハッシュタグの数（上限30個）が表示され、上限を超えると赤字になる
4. 「投稿文をコピー」を押してInstagramアプリに貼り付けて投稿する
5. ステータスを選んで「保存」する

作成後に講座や種類を変えると、雛形から作り直されます。手直しした後の場合は、作り直すかどうかの確認が出ます。「雛形から作り直す」ボタンでも作り直せます。

**雛形の差し込み項目** 雛形の本文には次の項目を書くことができ、投稿文を作るときに講座の情報に置き換わります。

| 差し込み項目 | 置き換わる内容 |
| --- | --- |
| {講座名} | 講座名 |
| {開催日} | 開催日（例：2026年10月17日（土）） |
| {時間} | 講座の開始〜終了時刻（講師依頼時間ではなく講座の時間） |
| {開催日時} | 開催日と時刻 |
| {会場} | 開催場所 |
| {担当科} | 担当科 |
| {研修形式} | 研修形式 |
| {開催日までの日数} | 今日から開催日までの日数 |
| {申込数} | 参加者募集フォームの申込件数 |
| {参加人数} | 提出済みの月次報告書に記載された参加人数 |
| {講座内容} | 講座案内PDFから読み取った講座の内容 |
| {講師} | 講座案内PDFの「講師」「講演者」「登壇者」の欄 |
| {対象} | 講座案内PDFの「対象」「対象者」の欄 |
| {定員} | 講座案内PDFの「定員」の欄 |
| {参加費} | 講座案内PDFの「参加費」「受講料」「会費」などの欄 |
| {申込締切} | 講座案内PDFの「申込締切」「申込期限」の欄 |
| {案内PDFの内容} | 講座案内PDFから読み取った全文の冒頭（最大400文字） |

講座の情報が登録されていないなどで差し込めなかった項目は「◯」になり、その理由が黄色の注意書きで表示されます。投稿前に書き換えてください。

**講座案内PDFの読み取り（OCR）** 雛形に講座案内PDFから拾う項目が含まれている場合、投稿文を作るときに、その講座の講座案内PDFを文字として読み取り、該当する部分を差し込みます。

* 読み取りは初回だけ10〜20秒ほどかかります。読み取った結果は保存され、同じ講座の2回目以降はすぐに作られます。講座案内PDFを差し替えると、次回は自動で読み取り直します
* PDFから読み取れなかった項目は、その項目を含む行ごと省きます
* 「講座案内PDFから読み取った全文を見る」で、読み取った文字をすべて確認できます。「PDFを読み直す」で読み取り直せます
* チラシのレイアウトによっては誤って拾ったり拾えなかったりするため、投稿前に必ず内容を確認してください

**雛形の変更** 「SnsTemplates」シートの「本文」「ハッシュタグ」の列を書き換えるだけで、次に作る投稿文から新しい雛形が使われます。Instagramのキャプションに書いたURLはリンクにならないため、申込先はプロフィールのリンク（tema.jp）に誘導する文面にしています。

**投稿用の画像（正方形）** 「講座案内PDFから画像を作る」を押すと、講座案内PDFの各ページを、Instagram用の正方形の画像（1080×1080ピクセル、JPEG）にします。まわりに白い余白を付けて中央に配置し、最初の10ページまでを画像にします。「◯ページ目を保存」「すべて保存」で保存でき、スマホでは画像を長押しして「写真に保存」でも保存できます。PDFにフォントが埋め込まれていない場合は、文字の書体が元のチラシと変わることがあります。

**投稿の記録（ステータス）**

* 下書き — 作成しただけの状態
* 投稿予定 — 投稿予定日を決めた状態。投稿予定日は必須。初期値は、募集告知が今日、開催前リマインドが開催7日前、開催報告が開催翌日
* 投稿済み — 投稿した状態。投稿日と、投稿のURL（任意）を記録できる

投稿予定日を過ぎても「投稿済み」になっていない投稿文は「予定日超過」（赤）と表示され、ページ上部にまとめて表示されます。

**講座別（初期表示）** 講座を行、3種類の投稿を列にした表です。各欄に投稿文の状態が表示され、押すと編集画面が開きます。まだ作っていない欄には「＋ 作成」が表示されます。

**投稿一覧** 作成した投稿文を「投稿予定」「下書き」「投稿済み」に分けて一覧表示します。「投稿文をコピー」「開く・編集」ができ、投稿のURLを記録したものは「投稿を開く」からInstagramの投稿を開けます。

**削除** 編集画面の「削除」で投稿文を削除できます（確認あり）。画面からは消えますが、記録としてはスプレッドシートに残ります。

## 参加者募集フォーム連携

各講座でGoogleフォームを使って申込を受け付けている場合、フォームの回答が入るGoogleスプレッドシートのURLを講座進捗ページの「⑤ 参加者募集フォーム」欄に貼り付けておくと、会場参加・ZOOM参加それぞれの申込件数を自動集計し、ダッシュボードや講座進捗ページに表示できます。集計結果は月次報告書の参加者数の自動入力にも使われます。フォームを使わない講座は、講座準備進捗確認で「不要」にチェックを付けてください。

別のGoogleアカウントで作成したフォームでも、回答用スプレッドシートをこのシステムが使っているGoogleアカウントに「閲覧者」として共有すれば集計対象にできます。「集計を更新」ボタンを押すと、その場で最新の件数が取得されます。

集計結果は「合計：N件（会場：N件／ZOOM：N件）」の形式で表示されます。会場／ZOOMの判定は、回答スプレッドシートの見出し行から「参加方法」「会場」「ZOOM」などのキーワードを含む列を自動で探して行います。うまくいかない場合は、「詳細設定」で判定に使う列の見出し文字列を指定できます。

スプレッドシートにアクセスできない場合は「このスプレッドシートにアクセスできませんでした。共有設定（このシステムのGoogleアカウントを閲覧者として共有）をご確認ください。」と表示されます。

## 請求書管理（請求書管理簿）

「請求書管理簿」は、請書兼請求書（講師依頼請書兼請求書）を作成・編集・一覧管理し、講師に送付する専用リンクを発行するページです。利用には「請求書アクセス」権限が必要です。

**一覧画面** 作成済みの請求書が一覧表示され、各行には講演テーマ、担当理事、開催日時（講座の時間。講師依頼時間が異なる場合は下に併記）、謝礼（税抜）、ステータス、最終更新者・日時が表示されます。ステータスは次の4種類です。

* **作成済み** — 請求書を作成し、講師の確認待ちの状態
* **確定済み** — 講師が内容（銀行口座情報など）を確定済みの状態
* **支払い済み** — 支払いが完了した状態
* **取消** — 取り消し済み（記録としては一覧に残る。元には戻せない）

**並び順とページ送り** 未完了（作成済み・確定済み）の請求書が上に、支払い済み・取消の請求書が下に並びます。境目には「完了（支払い済み）・取消の請求書」という区切りの行が入ります。同じ区分の中は作成の新しい順です。一覧は10件ごとにページが分かれ、表の下の「全◯件中 ◯〜◯件を表示」と「‹ 前へ／ページ番号／次へ ›」で移動します。10件以下のときはページ送りは表示されません。

開催日が近いのに請求書がまだ作成されていない講座がある場合は、一覧の上部に「⚠ 請求書が未作成の講座があります」というバナーが表示され、「＋この講座で作成」ボタンからすぐに新規作成できます。また、講師側の返信が遅れている場合は「講師側未返信」、支払期日が近い・過ぎている場合は「支払期限接近」「支払期限超過」のアラートが各行に表示されます。

**各行の操作** 各行には「確認・印刷」と「その他の操作」のボタンがあります。

* **確認・印刷** — 講師用請求書ページを新しいタブで開く
* **その他の操作** — 押すと次の操作が選べる
  * 案内文とリンクをコピー — 講師への案内文と講師用リンクをまとめてコピーする（講師用リンクをコピーし直すときはここ）
  * 編集 — 理事側が入力した内容（謝礼額・日時など）を直す（取消以外）
  * 支払い済みにする — 確定済みの請求書のみ
  * 講師に差し戻す（修正してもらう） — 確定済みの請求書のみ（後述）
  * 取消 — 理由を入力して取り消す（取消以外）

**講師の確定を差し戻す（修正してもらう）** 講師が「内容を確定する」を押した後は、講師本人はリンクから内容を変更できません。講師が入力した内容（振込先・住所など）に修正が必要な場合は、「その他の操作」→「講師に差し戻す（修正してもらう）」を押し、差し戻す理由を入力します（空欄でも可）。請求書が「作成済み」に戻り、講師は同じリンクを開くと、前回の入力内容が入った状態から修正して、もう一度確定できます。

* 差し戻せるのは「確定済み」の請求書だけです。「支払い済み」「取消」は差し戻せません
* 謝礼額・開催日時など、理事側が入力した項目を直すときは、差し戻しは不要です（「編集」で直せます）
* 誰がいつ、どんな理由で差し戻したかは操作の記録（ActivityLog）に残ります
* スプレッドシートを直接書き換える方法は、記録が残らず、講師の署名と内容が食い違うため、原則として使いません

**新規作成・編集** 「＋ 新規作成」ボタン、または講座進捗ページ・講座一覧バナーからの導線で入力画面が開きます。冒頭の「講座から選択」で講座を選ぶと、開催日・講座の時間・講師依頼時間・場所・講演テーマ・研修形式・担当理事・担当科が自動入力されます。入力項目は大きく4つに分かれます。

1. **研修・講演概要** — 開催日、担当理事名、講座の開始／終了時刻、講師依頼時間（開始／終了）、開催場所、講演テーマ、研修形式、担当科
2. **謝礼金・条件** — 謝礼本体金額（税抜）、交通費・宿泊費の扱い（「含む」／「別途支給」）、支払方法（銀行振込／現金）、支払予定日。入力と同時に消費税額・小計（税込）・源泉徴収税額（個人を仮定した概算）・差引お支払総額が計算・表示される
3. **準備機材等（主催者側で用意するもの）** — プロジェクター、PC、マイク、ホワイトボード、控室、スクリーンのチェック項目
4. **登壇者様へのメッセージ（任意）** — 請書兼請求書に記載され、講師の画面に表示されるメッセージ

支払予定日は、開催日が25日までならその月の月末日、それ以降なら翌月10日が初期値として自動入力されます。

**謝礼がない場合（謝礼0円の請書）** 謝礼が発生しない場合も、請書は作成します。謝礼本体金額を0円にして保存すると、講師用ページでは振込先とインボイスの欄が表示されず、講師には内容の確認と署名だけをお願いする形になります（交通費・宿泊費が「別途支給」で実費の入力があった場合は、その分の振込先を入力してもらいます）。講師が確定した時点で支払いまで完了とみなし、一覧では「謝礼なし（支払い不要）」と表示され、完了のグループに並びます。支払い待ちタスクや振込先一覧には出ません。

**見学会など、謝礼を当日持参する場合（現金）** 研修形式が「見学」の講座で新規作成すると、支払方法の初期値が「現金」になります。支払方法が「現金」の請求書は、講師用ページで振込先の欄が表示されず（「お支払いは当日、現金でお渡しします」と案内）、一覧では「現金（当日持参）」と表示されます。振込先一覧では、金融機関の欄に「現金（当日持参）」と表示されます。

保存すると（新規作成時のみ）「作成しました。以下のリンクを講師の方に送付してください（Googleログインは不要です）。」という案内とともに、講師用の専用リンクが発行されます。「コピー」を押すと、講師の方への案内文とリンクがまとめてコピーされるので、そのままメールやLINEで講師に送ります。後からコピーし直すときは、一覧の「その他の操作」→「案内文とリンクをコピー」を使います。

## 講師用請求書ページ

「講師依頼 請書 兼 請求書」は、担当理事が発行したリンクを開いた講師本人が、内容を確認したうえで自分の情報を入力・確定し、印刷（PDF保存）まで行うためのページです。Googleログインは不要で、請求書ごとに発行される固有のリンクだけでアクセスします。

**担当理事が入力済みで、講師からは変更できない項目**

研修・講演概要（開催日時（講座の時間）・講師依頼時間・開催場所・講演テーマ・研修形式・担当理事・担当科）と、謝礼に関する情報（謝礼本体金額、消費税、小計、源泉徴収税額、交通費・宿泊費の扱い、支払方法、支払予定日）、主催者側で準備する機材等、担当理事からのメッセージが表示されます。

**講師が自分で入力する項目（講師記入欄）**

* 交通費・宿泊費が「別途支給」の場合のみ、実費の金額
* 適格請求書発行事業者（インボイス）登録の有無と、登録ありの場合は登録番号
* 源泉徴収区分（個人／法人）と、それぞれに応じた氏名・会社名・連絡先・住所などの情報
* 振込先の金融機関名・支店名・口座種別・口座番号・口座名義（フリガナ）
* 写真・動画撮影および広報物掲載への許諾
* 担当科がスキルアップコース区分の講座の場合のみ、アーカイブ配信への許諾
* 提出日・署名（社名／氏名）

すべての項目が入力必須で、未入力の項目は赤枠とエラーメッセージで示されます。

**金額の計算方法**

差引お支払総額（実際に振り込まれる金額）は、次の式で計算されます（小数点以下は切り捨て）。

* 消費税 ＝ 謝礼（税抜）× 10%
* 小計（税込） ＝ 謝礼（税抜）＋ 消費税
* 源泉徴収税額 ＝ 謝礼（税抜）× 10.21%（源泉徴収区分が「法人」の場合は0円）
* 差引お支払総額 ＝ 小計（税込）－ 源泉徴収税額 ＋ 交通費・宿泊費（別途支給の場合のみ）

この計算式は、講師用請求書ページ・請求書管理簿・ダッシュボードのすべてで共通です。

**確定・印刷**

内容を入力したうえで「内容を確定する」ボタンを押すと、ステータスが「確定済み」になり、以降は講師自身では内容を変更できなくなります。確定後のページには「この内容で確定済みです。内容を変更する場合は、担当理事までご連絡ください（担当理事が差し戻すと、このページから修正して再確定できるようになります）。」と表示されます。修正が必要なときは、担当理事が請求書管理簿で「講師に差し戻す」を行います。

* 交通費・宿泊費は「別途支給」の場合だけ受け付け、100万円を超える金額は受け付けません
* 取消になった請求書のリンクを開いても、講師の個人情報や振込先は表示されません
* 支払い済みになってから3日が過ぎると、講師用リンクでは口座番号が下4桁だけ（例：＊＊＊4567）になり、金融機関名・支店名・口座名義は「＊＊＊」と伏せて表示されます。請求書アクセスのある理事が、理事ポータルにログインしたまま開いた場合は、確認のためすべて表示されます

確定後は「確定内容を印刷 / PDF保存」ボタン、未確定の状態では「印刷 / PDF保存」ボタンから印刷・PDF保存ができます。

**印刷の仕上がり** 印刷するとA4縦・2ページに収まります（1ページ目：表題・理事からのメッセージ・研修・講演概要・謝礼・準備する機材、2ページ目：講師記入欄・署名）。印刷では、補足の文字や入力欄の文字も含めてすべて黒で印刷され、入力欄は下線だけの記入済みの形で表示されます。印刷画面の「余白」は「デフォルト」、「倍率」は既定（100）のままにしてください。余白を大きくしたり倍率を上げたりすると3ページになることがあります。

リンクが無効な場合は「このリンクは無効か、期限切れの可能性があります」、通信障害など一時的に読み込めない場合は「一時的に読み込めませんでした」と表示されます。

## 印刷・出力機能（振込担当者向け一括印刷）

理事ポータルのダッシュボードにある「支払い待ちタスク」カードの「振込担当者用に一括印刷」ボタンから、支払いが済んでいない請求書をまとめた一覧を開けます。

一覧のタイトルは「支払い待ち請求書 振込先一覧」で、作成日が併記されます。支払予定日が近い順に、1件ずつ番号付きのカードで表示され、各カードには次の項目がすべて表示されます。

講座名／講師名／支払予定日／振込金額／金融機関／支店名／口座種別／口座番号／口座名義（カナ）

最後に「合計（◯件）」と合計金額が表示されます。支払い待ちの請求書がない場合は、「支払い待ちの請求書はありません。」とだけ表示されます。

「印刷する」ボタンを押すと、この一覧だけが印刷されます（前後に白紙のページは入りません）。印刷画面で用紙の向きを選べます。

* 縦向き：1件の請求書が3行で表示される
* 横向き：1件の請求書が2行で表示される

どちらの向きでも、長い講座名や口座名義は折り返して、すべての項目が表示されます。1件のカードがページの境目で分かれることはありません。「PDFに保存」を選べば、振込担当者に渡すPDFとしても保存できます。

## 月次報告書（ベータ版）

「月次報告書」は、担当科ごとに毎月の活動を報告し、理事会で配布する月次報告書PDFを作成するページです。ログインした理事であれば、どの担当科の報告書でも作成・編集できます。現在はベータ版（調整中）です。

**画面構成** 上部に月度の選択欄、「役員会の設定」ボタン、「月次PDF作成」ボタンが並びます。その下に、選んだ月度の提出期限が表示されます。担当科ごとの報告書がカードで並び、各カードには「提出済み」（緑）、「下書き」（黄）、「未提出」（グレー）のバッジが付きます。未提出の担当科がある場合は「⚠ 未提出の科があります」というバナーが表示され、提出期限を過ぎると赤色に変わります。

**報告書の入力項目** カードをクリックすると入力画面が開きます。

* **報告者** — 報告者の氏名
* **直近の講座開催** — 「＋ 講座を追加」で行を増やし、講座ごとに講座名・開催日・会場参加人数・ZOOM参加人数を入力する。登録済みの講座を選ぶと開催日が自動入力され、参加者募集フォームが設定されている講座なら人数も自動集計して入力される
* **その他報告内容** — 自由記述
* **課題・改善点等** — 自由記述
* **添付ファイル** — 「＋ ファイルを添付」でファイルを添付・削除できる

「🖼 画像を挿入」を押して画像を選ぶと、入力欄のカーソル位置に `[image:…]` という目印が挿入され、PDFを作成するときにその位置に画像が差し込まれます。

**保存・提出** 「下書き保存」で途中まで保存でき、「提出する」で提出済みになります。添付ファイルが1件以上あれば、ファイルだけでも提出できます。

**提出期限と役員会の設定** 「役員会の設定」から、年度（4月～翌3月）ごとに12か月分の役員会の開催日をまとめて登録できます。各月度の報告書の提出期限は、その月度以降で最初に開かれる役員会の2日前になります。役員会の開催日を登録すると、共有Googleカレンダーにも予定として自動登録されます。

**月次報告書PDFの作成** 「月次PDF作成」を押すと、選択中の月度で「提出済み」になっている報告書だけを、担当科の五十音順に1つのPDFにまとめます。作成したPDFは新しいタブで開き、Googleドライブの「理事ポータル_報告書添付」フォルダに保存されます。

PDFには、担当科ごとに「01 直近の講座開催」「02 その他報告」「03 課題・改善点」「04 添付資料」が掲載されます。添付ファイルのうち画像は、報告の後に1枚ずつ1ページに掲載されます。PDF・Wordなど画像以外の添付ファイルは、PDFの中ではリンクとして掲載されます（仕様であり不具合ではありません）。

## 資料庫（資料庫＆管理簿）

「資料庫」は、各講座の資料をまとめて保管・管理するページです。理事がアップロードした資料と、講師が専用リンクから提出した資料を、講座ごとに同じ場所で管理できます。ログインした理事であれば誰でも利用できます。

**一覧画面（管理簿）** 登録済みの講座が表で一覧表示されます。列は「講座名／担当科／開催日／資料件数／最終更新／操作」です。資料件数は「理事 ◯件」と「講師 ◯件」に分けて表示されます。「担当科で絞り込み」と「講座名で検索」で絞り込めます。スマホでは講座ごとのカードで表示されます。

**講座ごとの資料画面** 各講座の「資料を管理」ボタンを押すと、その講座の資料画面が開きます。

1. **講師用リンク** — この講座の講師に送る資料提出用のリンク。「コピー」を押すと、講師の方への案内文とリンクがまとめてコピーされる。リンクは講座ごとに1つで、発行の手続きは不要
2. **資料一覧** — 理事・講師どちらが登録した資料も表示される。ファイル名を押すとGoogleドライブのファイルが開く。「削除」ボタンで削除できる
3. **資料を追加（理事アップロード）** — 資料区分を選び、必要ならメモを入力してから「＋ ファイルを選択してアップロード」を押す

資料区分の選択肢は「教材・スライド」「配布資料(レジュメ等)」「準備資料」「写真・記録」「その他」です。理事がアップロードできるファイルは1つあたり20MBまでです。

**削除の扱い** 資料を削除すると画面から消え、Googleドライブのファイルはゴミ箱に移動します。誰がいつ削除したかの記録は残ります。

講座進捗ページの「④ 講師資料PDF」とは別の仕組みで、両者は連動していません。

## 講師用資料提出ページ

「講座資料のご提出」は、資料庫でコピーした講師用リンクを開いた講師本人が、講座で使う資料を提出するためのページです。Googleログインは不要です。

画面には案内文と、講座名・開催日時（講座の時間）・講師依頼時間・会場が表示されます。講師は、お名前（必須）、ひとことメモ（任意）、ファイル（必須。1回に1ファイル、20MBまで。PDF・Word・Excel・PowerPoint・Keynote・画像・動画・音声・テキスト・ZIPなど資料として一般的な形式のみ）を入力して「この資料を提出する」を押します。

1つの講座につき1日30件までの提出に制限しています。中止になった講座には提出できません。

講師のページに表示されるのは、その講座で講師が提出した資料のファイル名だけです。理事がアップロードした資料は表示されず、講師のページからファイルを開くこともできません。講師側からは資料を削除できないため、誤って提出した場合は担当理事が資料庫から削除します。

## セキュリティと運用上の注意

* ログインが必要な機能は、すべてサーバー側でGoogleアカウントの確認と名簿の照合を行います。請求書関連の機能は「請求書アクセス」の印がある理事だけが使えます
* 講師用リンクは推測できない長いIDで作られています。請求書は「作成済み」のときだけ講師が確定でき、確定後はリンクから書き換えられません
* 講座案内PDF・資料庫の資料・報告書の添付・月次報告書PDFは、名簿に登録された理事だけが閲覧できます。理事がファイルを開くときは、ブラウザで名簿に登録したGoogleアカウントにログインしている必要があります
* 講座名・コメントなど、入力した文字は文字として扱われ、プログラムとして実行されることはありません
* 2人が同時に保存しても、片方の変更が消えないようにしています（混み合った場合は「少し待ってからもう一度お試しください」と表示）
* 共用のパソコンで使ったときは、必ず「ログアウト」を押してください
* 講師用リンクは、送付先の講師以外に転送しないよう案内してください

## 管理者向けの設定（スプレッドシート）

| やりたいこと | 方法 |
| --- | --- |
| 理事を追加する／外す | 「AllowedAccounts」シートに行を追加／削除。すぐ反映したいときはApps Scriptで「clearAccountCache」を実行 |
| 請求書を使える理事を変える | 「AllowedAccounts」シートの「請求書アクセス」欄に印（例：○）を付ける／消す |
| 担当科を追加する | 「Departments」シートに行を追加 |
| 備品チェックの項目を変える | 「PulldownOptions」シートの区分「講座準備チェック項目」の行を編集 |
| 開催場所・研修形式・資料区分の選択肢を変える | 「PulldownOptions」シートの該当する区分の行を編集 |
| 8段階の目安の時期・請求書アラートの基準を変える | 「Settings」シートの値を変更 |
| SNSの雛形を変える | 「SnsTemplates」シートの「本文」「ハッシュタグ」を書き換える |
| ログインできない理由を調べる | 「ActivityLog」シートで操作が login_denied／login_token_rejected の行を見る |

名簿に登録された理事は、初めてポータルを使ったときに、ファイル保存用のGoogleドライブのフォルダの閲覧者に自動で追加されます。名簿から外した理事の閲覧権限は、毎日午前4時ごろの自動実行で外れます。
